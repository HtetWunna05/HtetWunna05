# Wunna · HtetWunna05

I build software that helps people make everyday decisions. My projects look at questions like when a kitchen should reorder an ingredient, which suppliers to consider, and how a week of sleep lines up with changes in mood.

## Selected work

- **[Kitchen Inventory](https://github.com/HtetWunna05/math)** helps a restaurant decide when to reorder and how much to buy. It uses demand during supplier lead time to flag upcoming orders and compares quantity discounts when calculating order size. [Browse the tests](https://github.com/HtetWunna05/math/tree/HEAD/tests).
- **[Supplier Recommendation](https://github.com/HtetWunna05/SupplierRecommendation)** brings data cleaning and supplier recommendations into a Python app with a Streamlit interface. [Read the recommendation logic](https://github.com/HtetWunna05/SupplierRecommendation/blob/HEAD/recommend.py).
- **[Sleep & Mood Tracker](https://github.com/HtetWunna05/sleep_tracler)** turns daily check-ins into a personal sleep history. It calculates sleep duration from bedtime and wake-up time, then lets users review those records alongside mood, stress, and energy. [Explore the database schema](https://github.com/HtetWunna05/sleep_tracler/blob/HEAD/database/db.sql).

## Technical focus

I use Python and Streamlit for data tools, JavaScript for inventory calculations, and PHP with MySQL for applications that keep a history of user entries.

## Project background

The sleep tracker grew out of a Business Information System Analysis and Design project. It connects two sides of the system: people can set wellness goals and record check-ins, while administrators manage the lifestyle categories and content those people see.
